240 × 320 / SAME ACTIONS, DIFFERENT LABELS

Lebih singkat. Tetap jelas.

Bandingkan tiga layout dengan kondisi yang sama. Tombol di layar hanya simulasi; tidak mengontrol device.

Pilih aksi di salah satu layar untuk melihat state berikutnya di ketiganya.

Pilihan gue: B, dengan kontrol map dari C.

Ikon + label pendek untuk Start, Pause, Finish, dan Save GPX. Ikon saja untuk Back, zoom, dan recenter. Status dan konfirmasi tetap pakai kata-kata: ikon stop belum tentu berarti ride tersimpan.

Jangan mengecilkan font supaya muat. Ringkas label, pertahankan target sentuh minimal 44 × 44, dan pisahkan penjelasan dari tombol. Kolom A adalah pembanding verbose, bukan salinan persis setiap layar firmware.

Arti ikon & batasan review

Play = mulai/resume ride; dua garis = pause; bendera = finish; disk = save GPX; target = recenter; kamera = shutter; power = mematikan kamera. Semua ikon punya accessible name dan tooltip untuk review desktop. Tooltip bukan pengganti label pada layar sentuh.

Belum diuji di LCD atau saat bersepeda. Tombol kamera hanya memperlihatkan “Command requested”, bukan konfirmasi bahwa kamera merekam. Flow review lama tetap tersedia dan tidak diubah.
